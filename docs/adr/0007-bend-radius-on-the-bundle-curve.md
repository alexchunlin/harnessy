# Minimum bend radius is declared in millimetres per spec, and checked on the bundle's drawn curve

Alex's feedback on 2026-10-09 asked for bend radius enforced along the entire conductor, in the same breath as wires drawn as continuous curves instead of disconnected tubes. The two land together: the curve the 3D view draws is the curve the check measures. A wire spec and a cable spec declare a minimum bend radius in millimetres; a sheath spec may declare one too, because heat shrink and braid can be stiffer than what they cover. The agent that authors library entries converts a datasheet's multiple of outer diameter at write time, so the model holds one unit. A bundle's minimum is the largest of its conductors' and sheaths', because a bundle bends no tighter than its stiffest member, and one number per segment gives one finding instead of one per conductor. The measured curve runs from the end of a connector's strain relief, through the segment's tie points, straight through any point endpoint into the next segment, and ends at a breakout or splice, where the part fitted there is the transition. Strain relief is a length on the connector type, drawn as a straight stub, and a type with none draws no stub. The check is a core design rule, reading whatever 3D placement the project saves, so a segment with no placement and a spec with no radius are both silent. It is a warning, since the BOM is still right when a bend is too tight, and it is silenced per segment. The 3D view turns the offending stretch of tube red and the finding prints the measured radius beside the allowed one. The topology view shows nothing beyond the segment lighting on selection. The repo library's wires, cables and sheaths get a radius from datasheets or rules of thumb now, and the authoring skill requires one on new entries. The decision was made on the ticket [How is bend radius declared, and how is it checked?](https://github.com/alexchunlin/harnessy/issues/33).

## Considered options

- Radius as a multiple of outer diameter, converted at check time. Rejected: the check and the BOM already think in millimetres, and two units on one field invite a wrong reading.
- A bundle radius that grows with bundle diameter. Rejected: no formula worth trusting; the fitting will say whether the stiffest member is enough.
- A curve per conductor route, so a net is checked end to end through breakouts. Rejected: every conductor in a bundle follows the bundle's curve, and at a breakout the fitted part sets the bend, not the conductors.
- An error that blocks export. Rejected: the glossary reserves errors for a wrong BOM, and this one is right.
- A project default such as six times outer diameter when a spec has none. Rejected: the check would report an invented number as fact.
- A fixed stub length instead of strain relief on the connector type. Rejected: a bend at the housing is the most common real failure and the housing is where the number belongs.
- The check living in the 3D view and running only while it is open. Rejected: a finding that vanishes when a view closes is not a design rule check.
